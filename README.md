# 장편 원고 편집실

태블릿 브라우저에서 바로 열어 쓰는 개인용 장편 원고 검수 도구입니다.

## 접속 주소

GitHub Pages를 켜면 아래 주소로 접속합니다.

https://asd6221-maker.github.io/writing-studio/

## 중요한 점

- 이 저장소에는 앱 코드만 올렸습니다.
- 실제 원고, 전체 설정 백업 JSON, 개인 작업 자료는 저장소에 올리지 마세요.
- 원고는 접속한 브라우저의 저장소에 보관됩니다.
- 기기를 바꾸기 전에는 앱 안에서 전체 JSON 백업을 내려받아 개인 드라이브에 따로 보관하세요.
- AI API, 서버, 로그인 기능은 없습니다.

## 태블릿 사용 흐름

1. GitHub Pages 주소를 엽니다.
2. 브라우저 메뉴에서 홈 화면에 추가합니다.
3. 원고를 붙여넣습니다.
4. 오류 검수, 반복 표현, 맥락 검색을 실행합니다.
5. ChatGPT 프롬프트를 복사해 검토에 사용합니다.

## Pages 설정

GitHub 저장소의 Settings → Pages에서 Source를 Deploy from a branch로 고르고, Branch는 main / root로 선택하면 됩니다.
