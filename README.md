# 장편 원고 편집실

여러 작품의 기준집과 원고를 분리해 관리하는 개인용 소설 편집 웹앱입니다. React + Vite + TypeScript로 구성하며 서버, AI API, 유료 서비스 없이 브라우저에서 동작합니다.

## 접속 주소

[장편 원고 편집실 열기](https://asd6221-maker.github.io/writing-studio/)

## 중요한 점

- 이 저장소는 일반 앱 코드와 빈 초기 데이터만 포함합니다. 실제 작품명, 인물, 설정, 원고를 기본 데이터로 제공하지 않습니다.
- 사용자가 입력한 자료는 현재 기기·브라우저·사이트 주소에 연결된 IndexedDB에 자동 저장합니다. 원고 전송 코드, 계정 로그인, 클라우드 동기화, 분석 추적 도구가 없습니다.
- GitHub Pages는 빌드된 앱 파일만 제공합니다. 사용자가 앱 안에 입력한 자료는 GitHub 저장소나 배포 산출물에 들어가지 않습니다.
- 백업 JSON은 개인 파일입니다. 저장소에 업로드하지 마세요. 기본 파일명은 작품명을 포함하지 않습니다.
- 브라우저 자료 삭제, 사생활 보호 모드 종료, 저장 공간 정리 시 자료를 잃을 수 있습니다. 작업 후 JSON을 개인 저장 공간에 백업하세요.
- 앱이 만드는 프롬프트는 자동 전송하지 않습니다. 사용자가 외부 AI에 붙여넣은 자료는 해당 서비스에 전달됩니다.

## 태블릿 사용 흐름

1. Safari 또는 Chrome에서 위 주소를 열고 **작품 서재 → 새 작품 만들기**를 누릅니다.
2. **작품 기준집**에 기획·설정·문체 자료를 붙여넣고 인물, 장소, 복선, 타임라인, 문체, 관계·규칙 카드를 만듭니다.
3. **원고 서재**에서 권 → 장 → 회차 → 장면의 필요한 단위만 만듭니다. 상위 목차를 선택해 연결하고, 같은 목차 안에서는 위/아래 이동으로 순서를 바꿉니다.
4. 긴 원고는 TXT·MD 또는 붙여넣기로 가져옵니다. 제목 줄 또는 구분선 분리 후 미리보기를 확인합니다. 분리 전 원문 전체도 별도로 보관합니다. Word·한글·PDF는 본문 복사 또는 UTF-8 TXT 저장을 이용하세요.
5. **확장본·후보**에 AI 확장본을 붙여넣고 원본과 비교합니다. 문단을 체크하거나 문장을 직접 선택해 후보로 저장합니다. 후보 메모와 복사를 이용해 최종본에 직접 반영합니다.
6. **검수**에서 원본·확장본·최종본 중 대상을 고릅니다. 등록한 금지어·주의어·규칙·반복 묶음을 확인하고 장면 기준을 직접 점검합니다.
7. **맥락 검색**으로 관련 카드를 찾고 포함할 카드와 다른 원고를 선택합니다. 원고를 바꾸면 검색을 다시 실행합니다.
8. **프롬프트**에서 검토 목적을 고르고 복사해 ChatGPT나 Gemini에 직접 붙여넣습니다. 전체 재작성·자동 윤문·분량 늘리기를 금지하는 조건이 포함됩니다.
9. **백업**에서 전체/작품별 JSON, 기준집만 JSON, 원고 TXT·MD를 내려받습니다. 기기 변경 시 같은 앱 주소에서 JSON을 복원하세요.

브라우저 메뉴의 **홈 화면에 추가** 또는 **앱 설치**로 PWA를 사용할 수 있습니다. 첫 방문은 인터넷이 필요합니다. 앱 파일의 기본 캐시를 제공하지만 브라우저별 오프라인·설치 지원에는 차이가 있습니다. 새 버전 알림은 저장 완료 후 적용합니다. 홈 화면 앱과 브라우저 저장소가 다를 수 있으므로 전환 전 백업하세요.

## 기능과 범위

- 작품 생성·선택·이름 수정·복제·삭제. 작품별 원고, 기준, 카드, 검색 선택, 프롬프트 종류를 분리합니다.
- 원본 / AI 확장본 / 후보 / 최종본을 별도로 저장합니다. 후보 선택은 최종본을 바꾸지 않습니다.
- 원고 상태 8종, 장면 목적·등장인물·장소·복선·감정선·앞뒤 메모. 수동 버전 보관과 복원.
- 검수 결과는 필수 수정 / 확인 필요 / 선택 수정 / 유지 추천으로 표시하고 일치 구절과 행 번호를 제시합니다. 등록한 반복 묶음과 자동 집계한 반복 어절 상위 20개를 확인할 수 있습니다. 원고를 수정하면 수동 점검 체크를 비웁니다.
- 키워드 RAG-lite는 이름·별칭 5점, 키워드 3점, 직접 연결 카드 2점입니다. 연관 확장은 한 단계이며 반복 출현으로 점수를 부풀리지 않습니다.
- 프롬프트 7종: 장면 완성도, 감정선, 캐릭터 톤, 확장본 취사선택, 앞뒤 이음새, 최종본 패치 제안, 설정 충돌.
- 기준집 요약은 사용자가 작성한 요약입니다. 앱이 내용을 이해하거나 요약하지 않습니다. 프롬프트에 입력한 기준 항목의 원문도 포함합니다.
- 의미 기반의 캐릭터 이탈, 감정 급변, 사실 충돌은 자동 확정하지 않습니다. 등록된 문자열 규칙의 후보 표시와 수동 체크리스트, 외부 AI 검토용 프롬프트를 제공합니다.
- 확장본의 ‘원본과 다른 문단’ 표시는 정확히 같은 문단이 원본에 있는지 비교한 결과이며 의미 기반 차이 분석이 아닙니다.

## 저장과 복원

저장소: IndexedDB `writing-studio-personal`, `data` 객체 저장소의 `workspace` 항목. 자료 형식 버전은 2입니다. 변경 후 자동 저장하며 화면의 저장 완료 표시를 확인하세요. 다른 탭의 오래된 저장은 충돌로 중단해 최신 자료를 덮어쓰지 않습니다. 충돌한 탭은 현재 작업을 백업한 뒤 새로고침하세요.

- 전체 JSON 복원: 현재 서재 교체. 미리보기와 확인이 필요하며 교체 전 백업 버튼을 제공합니다.
- 작품 JSON 복원: 새로운 ID의 별도 작품으로 추가. 기존 작품을 덮어쓰지 않습니다.
- 기준집 JSON: 기준·카드·검사 규칙만 포함. 원고·후보·가져오기 초안은 포함하지 않습니다.
- 원고 내보내기: 전체 작품 또는 특정 권/장/회차/장면과 그 하위 원고. 선택 버전만 출력하며 빈 최종본을 원본으로 대체하지 않습니다.
- 기존 공개 편집실의 `localStorage['writing-studio-v1']`는 동일한 사이트 주소에서 처음 실행할 때 별도 작품으로 가져옵니다. 원래 키는 삭제하지 않습니다. 이 형식의 기존 JSON 백업도 가져올 수 있습니다. 다른 프로그램의 백업 형식은 지원하지 않습니다.
- 잘못된 JSON, 중복 ID, 잘못된 목차·상태·참조는 복원 전에 거부합니다.

## 프로젝트 구조

```text
writing-studio/
  src/
    App.tsx          작품 서재와 편집 화면
    model.ts         작품·목차·후보·분리·내보내기
    storage.ts       IndexedDB, 검증, 백업, 이전 자료 이관
    engine.ts        표현 검수, 맥락 검색, 프롬프트
    core.test.ts     데이터 보존·격리·복원 검증
    main.tsx
    style.css        태블릿 반응형 화면
  public/            일반 앱 아이콘
  scripts/           공개 소스 검사
  .github/workflows/pages.yml
  vite.config.ts     Pages 하위 경로와 PWA
  package.json
```

## 개발 및 검증

Node.js 24를 사용합니다. 일반 사용자는 PC에서 실행할 필요가 없습니다.

```sh
npm ci
npm test
npm run audit:privacy
npm run build
npm run dev
```

로컬 개발 주소는 터미널에 표시된 주소의 `/writing-studio/` 경로입니다. 개발 주소의 자료와 배포 주소의 자료는 서로 다른 저장소입니다. JSON으로 옮겨야 합니다.

## Pages 설정

GitHub 저장소의 **Settings → Pages → Source → GitHub Actions**를 선택합니다. `main`에 푸시하면 의존성 설치 → 테스트 → 공개 소스 검사 → 빌드 → `dist`만 업로드 → Pages 배포가 실행됩니다. 저장소 전체를 배포하지 않습니다. `base`는 `/writing-studio/`입니다.

구성 참고: [GitHub Pages 공식 문서](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [Vite PWA 업데이트 안내](https://vite-pwa-org.netlify.app/guide/prompt-for-update).
